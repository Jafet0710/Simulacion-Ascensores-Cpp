Desafío Lógico Resuelto
El proyecto resuelve la gestión de rutas óptimas mediante el análisis del estado del edificio (pisos totales) y la posición relativa del usuario:
Simulación de Animación en Consola: Uso de temporizadores por hardware (`Sleep`) para renderizar de manera interactiva el ascenso y descenso en tiempo real del elevador a través de una interfaz gráfica basada en caracteres (ASCII Art).
Control de Excepciones Dinámico: Validación estricta de límites físicos del edificio para mitigar desbordamientos lógicos (rutas a pisos inexistentes o fuera de rango).
Estructura Modular: Implementación avanzada mediante la separación de responsabilidades: Prototipos de funciones, Controladores de Interfaz (`menu`/`saludo`), y Núcleos de Ejecución Logística (`ascensor1`).

Especificaciones Técnicas
Lenguaje: C++ (Estándar C++11 o superior).
Librerías del Sistema Utilizadas:** `<windows.h>` (Gestión de hilos y retardos), `<stdio.h>` y `<stdlib.h>` (Controladores de flujo de consola).
Paradigma: Programación Estructurada y Modular de Alta Cohesión.

Cómo Ejecutar la Simulación
1. Descarga el archivo de código fuente `Proyecto2_Ascensores.cpp`.
2. Compílalo en cualquier entorno compatible con Windows (Visual Studio, Dev-C++).
3. Ejecuta el binario generado para iniciar la simulación interactiva.
